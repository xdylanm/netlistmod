# LTspice scoping

The scope model of the document layer for LTspice (architecture §8;
[decision 0009](../../decisions/0009-ltspice-dialect.md)). Rules S1–S11 of
[the ngspice document](../ngspice/scoping.md) were re-probed on LTspice 26.1.1. The model is the
same, and the rows that differ say so. The implementation is `src/netlistmod/document/index.py`; it
branches on the dialect only where a row says so. The probes are in
`tests/solver/test_ltspice_solver_document.py`. A rule LTspice also tolerates in a form the library
rejects keeps its status and has a row in [discrepancies.md](./discrepancies.md).

Validated on: ltspice 26.1.1 (2026-11-01)

## Includes

As for ngspice, the library never reads `.include`/`.lib` files (§7.8). An `UNRESOLVED_*` diagnostic
whose searched scopes contain one is **info**. LTspice's bundled device libraries are not visible
either: a diode naming a bundled model with no `.lib` line gets `UNRESOLVED_MODEL` (warning).
