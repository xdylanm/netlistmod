# 0014 — Transistors

- **Status:** proposed (M13; accepted when M13 closes)
- **Date:** 2026-11-05
- **Context:** M13 adds the transistor letters Q, M, J and Z on both dialects. A transistor line has a variable number of nodes before its model, and neither solver decides where the nodes end by syntax: both look up which names are defined models. Probes on ngspice 47 and LTspice 26.1.1 are in [m13-tasks.md](../design/m13-tasks.md) section 3. The maintainer accepted these on 2026-11-05.
- **Decision:**
  1. **The boundary rule.** The model is the last name before the first area value, flag, parameter or the end of the line. The grammar spells out the name sequences each letter's node counts allow, so the parser classifies a name once it sees what follows it, as for an X line. A field written as a number is a node before the model and an area after it. Where only a name may follow, the lexer reads a number or the keyword `off` (or `thermal` on an ngspice M) as a name; the transformer refuses it as the model at its token (P13). For `Q1 c b e qm s` the rule takes `s` as the model, as ngspice does; LTspice stops.
  2. **Node counts by letter and dialect, without looking at the model's type.** Q takes 3 to 5 nodes on ngspice (substrate, then VBIC's junction temperature node) and 3 or 4 on LTspice. M takes 3 to 5 on ngspice (VDMOS 3, MOSFET 4, VDMOS with `thermal` 5) and 3 or 4 on LTspice. J and Z take exactly 3. A count that is wrong for a model, such as a 3-node NMOS line, parses and stops the solver.
  3. **Topology is the nodes written.** A 3-node Q grounds its substrate in ngspice, but the signature records only the written nodes. An LTspice export that writes a 3-pin VDMOS's source twice (`MQ8 d g OUT OUT 2N7000_OJ`) has two connections to one net, as written. The implicit substrate is a known limit (architecture §7.8).
  4. **Name forms one solver allows and the manual does not.** An instance's model named with a plain number (`Q1 c b e 2` after `.model 2 NPN`), which LTspice runs, is refused: a number in that place is read as an area. The `.model 2 NPN` line itself still loads. A node named `off` before the model (`Q1 c b e off qm`) is a node, as LTspice reads it; ngspice takes it as the model. `discrepancies.md` records both.
  5. **Area.** Positional on both dialects for J and Z, and on LTspice for Q. Named on an ngspice Q (`area=`, `areab=`, `areac=`); a positional area there, which ngspice 47 runs, is refused because the manual shows only the named form (decision 0002). On LTspice an embedded decimal (`1n5`) is an area only where no name may follow, so `Q1 c b e s 2N3904` reads `2N3904` as the model.
  6. **Instance parameters.** ngspice: open names, with the flags `off` and VDMOS's `thermal`. LTspice: closed lists from the reference: Q `temp`; M `L W AD AS PD PS NRD NRS m temp IC`, one list for the monolithic and VDMOS forms; J `temp`; Z `m temp`; `off` on all. Forms LTspice runs beyond those, such as `area=` on Q and `IC=` or `m=` on J, are refused and recorded. On both dialects `ic=` takes a comma list, with or without a blank after the comma.
  7. **`.model` forms.** A bare `pchan` or `nchan` is a flag in any `.model` parameter list, with or without parentheses. A dotted value such as `version=3.3.0` is text (`Identifier`), never a number. `set_model_param` edits values; adding or removing `pchan` is not offered.
  8. **Model types per dialect.** On both: Q takes NPN and PNP; M takes NMOS, PMOS and VDMOS; J takes NJF and PJF; Z takes NMF and PMF. On LTspice only, Z also takes NIGBT and PIGBT; ngspice reports "Unknown model type nigbt". `model-types.json` gains a per-dialect section.
  9. **The transformer and the edit operations are split by element family** (`model/_rules_*.py`, `edit/_ops_*.py`), with no change in behaviour (P12).
  10. **Corpus manifests may name external files.** A fixture's `solver` object may hold `external`, a map from a file name the netlist includes to the environment variable that gives its path (`{"jellybean.lib": "OPENJELLYBEAN_LIB"}`). The solver sweeps copy the file next to the netlist, and skip with the variable's name when it is unset. This amends decision 0008.
- **Amendments to the architecture:** §5.2 and §5.3 (the transistor nodes), §6.3 (rule 14, the boundary rule), §7.2 (the model types), §7.8 (the implicit substrate).
- **Consequences:**
  - `BipolarTransistor`, `Mosfet`, `Jfet` and `Mesfet` share `model`, `flags` and `area`; `ModelStatement` gains `flags`.
  - `set_param(…, "area", …)` writes the positional slot where the dialect has one, unless the line already writes `area=`; on an LTspice M it is an `EditError` because the line does not parse.
  - The tree snapshot adds the `kicad_transistors` family and the transistor golden files; 17 rejected files list the four letters among their expected terminals. The signature snapshot is unchanged.
  - Spec entries `NG-XTR-001` and `LT-XTR-001` hold the shared line shape, and `NG-`/`LT-` `BJT`, `MOS`, `JFT` and `MES` each letter. Tests that used Q as an example of a planned letter now use T.
