# netlistmod

`netlistmod` is a source-preserving SPICE netlist editing library. Its goal is
to make permitted value and directive edits while preserving the original text
and circuit topology.

The project is in early development. See [the architecture](docs/architecture.md)
for design invariants and [the Phase 1 plan](docs/design/phase-1-plan.md) for
scope and milestones. Local setup and checks are documented in
[testing](docs/testing.md).
